What "Done" Means

A task is complete when:

  1. Anti-slop gate passes — No forbidden patterns, aesthetic direction locked
  2. All applicable items pass — Automated checks pass, human checks verified
  3. Aether remains compliant — Changes don't break the product's own standards
  4. Documentation updated — HANDOVER.md and ROADMAP.md reflect the change
  5. Commit message states excellence impact

If any item fails, the task is not done.
