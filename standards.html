Standards Library

The rules Aether and the web-excellence skill enforce.

Anti-slop

  • One locked aesthetic direction (not “clean and modern”)
  • No purple/indigo default gradients, glassmorphism+neon, identical three-card grids
  • Strong hierarchy · real content · all four states designed

Accessibility (WCAG 2.2 AA)

  • Semantic HTML, one h1, landmarks, skip link
  • Visible focus never fully obscured · target size ≥ 24×24 CSS px
  • Contrast 4.5:1 text / 3:1 UI · labels on forms · reduced-motion

Performance

  • LCP ≤ 2.5s · INP ≤ 200ms · CLS < 0.1
  • Modern image formats · controlled fonts · minimal main-thread work

UX & Layout

  • Nielsen heuristics · loading/empty/error/success states
  • Mobile-first · Grid + Flex + container queries · fluid clamp()
